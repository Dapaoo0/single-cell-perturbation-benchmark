# Data provenance

## Original experiment

- Study: Norman et al., *Exploring genetic interaction manifolds constructed from rich single-cell phenotypes* (2019)
- Assay: pooled Perturb-seq with CRISPR activation/overexpression, including single and combinatorial perturbations
- GEO: `GSE133344`
- BioProject: `PRJNA551220`
- GEO record: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE133344>

## Processed representation

The execution pipeline supports a pinned GEARS-processed Norman AnnData artifact.
Its exact URL, source revision, download timestamp, byte size, and SHA256 must be
recorded in `results/metadata/source_provenance.json` before real analysis runs.
No scientific result may be reported while that provenance gate is incomplete.
